# データの編集ガイド

アプリが表示する年代・用語は、すべてこのフォルダの JSON ファイルに入っています。
テキストエディタや GitHub の画面で直接書きかえられます。

## ファイルの一覧

| ファイル | 中身 |
| --- | --- |
| `manifest.json` | 読み込むファイルの一覧。ファイルを増やしたらここに足す |
| `config.json` | 年の範囲 `range`（いまは `[500, 2000]`）、最初に開く年 `defaultYear`、幅 `windows`、スライダーの目印 `anchors`（`[年, "名前"]`。3つ目に優先度を書くと、幅が足りないとき優先度の低いものから省く：`[1840, "アヘン戦争", 1]`、省略は 2）、地図の表示範囲 `mapViews`、年表の下の帯グラフ `ganttRows` |
| `regions.json` | 地域（`cn` 中国・`kr` 朝鮮・`jp` 日本・`ia` 内陸アジア・`sea` 東南アジア・`sa` 南アジア・`wa` 西アジア・北アフリカ・`af` アフリカ・`ee` 東欧・ロシア（北欧をふくむ）・`ce` 中央ヨーロッパ（イタリアをふくむ）・`we` 西ヨーロッパ・`am` 南北アメリカ・`intl` 国際）と、クイズでの地域のまとめ方 |
| `polities.json`、`polities-0500-1499.json` | 王朝・国家（勢力図の範囲 `territory` をふくむ）。500〜1499年を足したときに新しく加えた国は `-0500-1499` のほう（マリ王国のように1500年以降まで続く国もふくむ）。もとからあった国（明・オスマン帝国など）を前にのばしたものは `polities.json` のまま。どちらに書いても動きます |
| `rulers.json`、`rulers-0500-1499.json` | 君主・指導者（500〜1499年を足したときに加えた人は `-0500-1499` のほう） |
| `events/0500-0599.json` 〜 `events/1900-2000.json` | 出来事（100年ごと） |
| `map/zones.json` | 勢力図の地形（`tools/build-map.mjs` が作る。ふつうは編集しない） |
| `map/ZONES.md` | 勢力図のゾーン名（`territory` で使う ID）の一覧 |

## すべての項目に共通の印

| 項目 | 意味 |
| --- | --- |
| `verified` | **用語集で年号の正確性を確認したら `true`**。最初はすべて `false` |
| `uncertain` | AI が年に自信がない・説が分かれると判断したら `true`。理由は `memo` |
| `memo` | メモ（別の説、用語集のページなど） |
| `importance` | 重要度 1〜3（3 が最重要）。クイズに出る回数と、年表で目立たせるかに使う |
| `desc` | 概要（1〜2文）。解答後に用語をタップすると出る |
| `descVerified` | **概要を確かめたら `true`**。概要は AI が自分の言葉で書いたもので、最初はすべて `false`（世界史の窓との照らし合わせはこれから） |
| `source` | （任意）概要を確かめたページの URL（例：世界史の窓のページ）。書くと概要の画面に「参照ページ」が出る |
| `image` | （出来事のみ・任意）作品・建築の写真の指定。下の「作品・建築の写真」を参照 |
| `imageVerified` | **写真が正しい作品・建築のものか確かめたら `true`**。最初はすべて `false`（画面に「画像は未確認」と出る） |

## 確かめる手順（おすすめ）

アプリの右上の ☑（データ確認）で、上の切りかえから「年号」「概要」「画像」のどれを確かめるかを選びます。

1. 「要確認」や「未確認」の一覧から始める
2. 年号は用語集で、概要は「世界史の窓で調べる」から出るページで、画像は写真を見て確かめる
   - 合っていれば「確認した」を押す
   - ちがっていれば「修正」で年・要確認の印・メモ・概要・画像の指定を直して「保存」（概要や画像の指定を直すと、その「確認済み」の印は外れます）
3. ここまでの変更は、そのブラウザの中だけに保存されます。画面の下の「（ファイル名）を書き出す」で JSON ファイルをダウンロードする
4. GitHub のリポジトリで `data/` の同じ名前のファイルを開き、書き出したファイルで置き換える
   （フォルダの画面で「Add file → Upload files」、またはファイルを開いて鉛筆マークで中身を貼り替え）
5. 置き換えが済んだら、アプリの「このブラウザの変更をすべて消す」を押す

JSON を直接直してもかまいません。たとえば確認した項目の `"verified": false` を `"verified": true` にします（概要なら `descVerified`、画像なら `imageVerified`）。

## 出来事（`events/*.json`）

```json
{
  "id": "e1648a",
  "year": 1648,
  "title": "ウェストファリア条約",
  "answers": ["ヴェストファーレン条約", "ウェストファリア"],
  "regions": ["ce", "we"],
  "importance": 3,
  "desc": "三十年戦争の講和。スイス・オランダの独立が承認され、…",
  "verified": false,
  "uncertain": false,
  "memo": ""
}
```

| 項目 | 必須 | 意味 |
| --- | --- | --- |
| `id` | ○ | 重ならない名前。新しく足すときは `"e1648x"` のように何でもよい |
| `year` | ○ | 年（紀元前はマイナス。`-221` は画面で「前221」と表示） |
| `end` |  | 期間がある出来事の終わりの年（例：三十年戦争 `1618`〜`1648`） |
| `month` |  | 同じ年の出来事を並べる順番にだけ使う（1〜12） |
| `title` | ○ | 名前（クイズの正解） |
| `answers` |  | 別の言い方。記述式でこれを書いても正解になる |
| `keywords` |  | 「A+B」の形で、A と B の両方が書かれていれば正解（例：`"ナポレオン+教皇"`） |
| `regions` | ○ | 地域の ID（複数可） |
| `tags` |  | `["文化"]` で文化史として扱う |
| `desc` |  | 概要（出来事当てのヒントにもなる。名前や別の言い方が入っていても、出題中は「＿＿」で伏せる） |
| `acceptYears` |  | 年代当てで正解にする別の年（説が分かれるとき。例：`[1649]`） |
| `image` |  | 作品・建築の写真（下を参照） |

ファイルの中の順番は自由です（アプリが年の順に並べます）。

### 作品・建築の写真（`image`）

写真そのものはデータに入れず、**表示するときに Wikimedia から取得**します。データには「どの写真か」だけを書きます。

| 書き方 | 意味 |
| --- | --- |
| `"ja:落穂拾い (ミレー)"` | 日本語版ウィキペディアのこの記事の代表画像 |
| `"en:The Gleaners"` | 英語版ウィキペディアのこの記事の代表画像 |
| `"File:Jean-François Millet - Gleaners - Google Art Project 2.jpg"` | Wikimedia Commons のこのファイル |

- パブリックドメイン・CC0・CC BY・CC BY-SA・GFDL など、利用条件がはっきりした自由なライセンスのものだけを表示し、作者・ライセンス・ファイルのページへのリンクを写真の下に出します。条件に合わない写真は表示しません。
- 記事の代表画像が作品でない（作者の肖像など）ときは、`File:` でファイルを直接指定すると確実です。
- 著作権が切れていない作品（20世紀の美術など）は指定しないでください。

## 王朝・国家（`polities.json`）

| 項目 | 意味 |
| --- | --- |
| `id`, `name` | ID と名前。`aliases` は別名（記述式で正解になる） |
| `region` | 地域の ID。王朝が国の中の一時期のときは、`region` の代わりに `parent` に国の ID を書く |
| `start`, `end` | 続いた期間。途中でとぎれるときは `"periods": [[1531, 1885], [1948, 2000]]` |
| `names` | 時期によって名前が変わるとき：`[[1871, "ドイツ帝国"], [1919, "ヴァイマル共和国"]]` |
| `color` | 勢力図の色（`#RRGGBB`） |
| `minor` | 小さな国。年表のカードでは「ほか：」の行にまとめる |
| `hideInCards`, `noQuiz` | 年表のカードに出さない／クイズに出さない |
| `desc` | 説明 |
| `territory` | 勢力図の範囲の変化（下を参照） |

### 勢力図の範囲（`territory`）

```json
"territory": [
  { "year": 1636, "add": ["manchuria", "manchuria-s"], "vassal": ["mongolia-in"], "note": "国号を清と改める" },
  { "year": 1645, "add": ["cn-jn", "cn-jx"], "contested": ["cn-hg", "cn-sc"], "note": "南京を占領" }
]
```

- `add` 直接の支配　`vassal` 属国・従属（淡い色）　`contested` 範囲が不確か・係争中（斜線）　`colony` 植民地（「〜領」と表示）　`remove` 手放した
- その年までの変化を順に重ね、**まだ続いている国のうち、いちばん最後に加えた国**の色で塗ります。国が終わったり `remove` したりすると、その前の持ち主に戻ります。
- ゾーンの ID は `map/ZONES.md` にあります。地図は現代の州・県の組み合わせなので、昔の国境は近似です。古代オリエントのように範囲がはっきりしない時代は `contested` を使うとよいでしょう。

## 君主・指導者（`rulers.json`）

```json
{ "id": "r-qing-1661", "name": "康熙帝", "aliases": ["聖祖"], "polity": "qing", "from": 1661, "to": 1722, "importance": 3, "verified": false, "uncertain": false, "memo": "" }
```

`polity` は王朝・国家の ID、`from`〜`to` は在位（在職）期間。`title` に称号（「首相」など）を書けます。

## JSON の書き方の注意

- 文字は `" "` で囲む（`true` `false` と数は囲まない）
- 最後の項目のあとに `,` を付けない
- 書き間違えると、アプリの画面に「○行目 ○文字目あたり」と場所が出ます。`npm run validate` でも点検できます

## 範囲を広げる（例：紀元前 500年〜2000年）

500〜1499年を足したときと同じ手順です。

1. `config.json` の `range` を `[-500, 2000]` にする（紀元前はマイナス）。`anchors` に目印を足す
2. 出来事のファイルを作り（例：`events/m0500-0001.json`）、`manifest.json` の `events` の一覧に足す
3. 王朝・国家と君主を足す。別のファイルに分けてもよい：`"polities": ["polities-ancient.json", "polities-0500-1499.json", "polities.json"]`
4. 古い時代まで続く国（例：ビザンツ帝国）は、元の項目の `start`・`territory` を前にのばす（同じ ID の国を2つ作らない）
5. 勢力図で、ある国が終わったあとに別の国の色が「よみがえる」ときは、その国の `territory` に `remove` を足す
6. `npm run validate` で点検する

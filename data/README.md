# データの編集ガイド

アプリが表示する年代・用語は、すべてこのフォルダの JSON ファイルに入っています。
テキストエディタや GitHub の画面で直接書きかえられます。

## ファイルの一覧

| ファイル | 中身 |
| --- | --- |
| `manifest.json` | 読み込むファイルの一覧。ファイルを増やしたらここに足す |
| `config.json` | 年の範囲 `range`、最初に開く年 `defaultYear`、幅 `windows`、スライダーの目印 `anchors`、地図の表示範囲 `mapViews`、年表の下の帯グラフ `ganttRows` |
| `regions.json` | 地域（`cn` 中国・`kr` 朝鮮・`jp` 日本・`ia` 内陸アジア・`sea` 東南アジア・`sa` 南アジア・`wa` 西アジア・北アフリカ・`af` アフリカ・`ee` 東欧・ロシア（北欧をふくむ）・`ce` 中央ヨーロッパ（イタリアをふくむ）・`we` 西ヨーロッパ・`am` 南北アメリカ・`intl` 国際）と、クイズでの地域のまとめ方 |
| `polities.json` | 王朝・国家（勢力図の範囲 `territory` をふくむ） |
| `rulers.json` | 君主・指導者 |
| `events/1500-1599.json` など | 出来事（100年ごと） |
| `map/zones.json` | 勢力図の地形（`tools/build-map.mjs` が作る。ふつうは編集しない） |
| `map/ZONES.md` | 勢力図のゾーン名（`territory` で使う ID）の一覧 |

## すべての項目に共通の印

| 項目 | 意味 |
| --- | --- |
| `verified` | **用語集で年号の正確性を確認したら `true`**。最初はすべて `false` |
| `uncertain` | AI が年に自信がない・説が分かれると判断したら `true`。理由は `memo` |
| `memo` | メモ（別の説、用語集のページなど） |
| `importance` | 重要度 1〜3（3 が最重要）。クイズに出る回数と、年表で目立たせるかに使う |

## 年を確かめる手順（おすすめ）

1. アプリの右上の ☑（データ確認）を開き、「要確認」や「未確認」の一覧から始める
2. 用語集で年を確かめる
   - 合っていれば「確認した」を押す
   - ちがっていれば「修正」で年・要確認の印・メモを直して「保存」
3. ここまでの変更は、そのブラウザの中だけに保存されます。画面の下の「（ファイル名）を書き出す」で JSON ファイルをダウンロードする
4. GitHub のリポジトリで `data/` の同じ名前のファイルを開き、書き出したファイルで置き換える
   （フォルダの画面で「Add file → Upload files」、またはファイルを開いて鉛筆マークで中身を貼り替え）
5. 置き換えが済んだら、アプリの「このブラウザの変更をすべて消す」を押す

JSON を直接直してもかまいません。たとえば確認した項目の `"verified": false` を `"verified": true` にします。

## 出来事（`events/*.json`）

```json
{
  "id": "e1648a",
  "year": 1648,
  "title": "ウェストファリア条約",
  "answers": ["ヴェストファーレン条約", "ウェストファリア"],
  "regions": ["ce", "we"],
  "importance": 3,
  "desc": "三十年戦争の講和。スイス・オランダの独立が承認され、…",
  "verified": false,
  "uncertain": false,
  "memo": ""
}
```

| 項目 | 必須 | 意味 |
| --- | --- | --- |
| `id` | ○ | 重ならない名前。新しく足すときは `"e1648x"` のように何でもよい |
| `year` | ○ | 年（紀元前はマイナス。`-221` は画面で「前221」と表示） |
| `end` |  | 期間がある出来事の終わりの年（例：三十年戦争 `1618`〜`1648`） |
| `month` |  | 同じ年の出来事を並べる順番にだけ使う（1〜12） |
| `title` | ○ | 名前（クイズの正解） |
| `answers` |  | 別の言い方。記述式でこれを書いても正解になる |
| `keywords` |  | 「A+B」の形で、A と B の両方が書かれていれば正解（例：`"ナポレオン+教皇"`） |
| `regions` | ○ | 地域の ID（複数可） |
| `tags` |  | `["文化"]` で文化史として扱う |
| `desc` |  | 説明（出来事当てのヒントにもなる） |
| `acceptYears` |  | 年代当てで正解にする別の年（説が分かれるとき。例：`[1649]`） |

ファイルの中の順番は自由です（アプリが年の順に並べます）。

## 王朝・国家（`polities.json`）

| 項目 | 意味 |
| --- | --- |
| `id`, `name` | ID と名前。`aliases` は別名（記述式で正解になる） |
| `region` | 地域の ID。王朝が国の中の一時期のときは、`region` の代わりに `parent` に国の ID を書く |
| `start`, `end` | 続いた期間。途中でとぎれるときは `"periods": [[1531, 1885], [1948, 2000]]` |
| `names` | 時期によって名前が変わるとき：`[[1871, "ドイツ帝国"], [1919, "ヴァイマル共和国"]]` |
| `color` | 勢力図の色（`#RRGGBB`） |
| `minor` | 小さな国。年表のカードでは「ほか：」の行にまとめる |
| `hideInCards`, `noQuiz` | 年表のカードに出さない／クイズに出さない |
| `desc` | 説明 |
| `territory` | 勢力図の範囲の変化（下を参照） |

### 勢力図の範囲（`territory`）

```json
"territory": [
  { "year": 1636, "add": ["manchuria", "manchuria-s"], "vassal": ["mongolia-in"], "note": "国号を清と改める" },
  { "year": 1645, "add": ["cn-jn", "cn-jx"], "contested": ["cn-hg", "cn-sc"], "note": "南京を占領" }
]
```

- `add` 直接の支配　`vassal` 属国・従属（淡い色）　`contested` 範囲が不確か・係争中（斜線）　`colony` 植民地（「〜領」と表示）　`remove` 手放した
- その年までの変化を順に重ね、**まだ続いている国のうち、いちばん最後に加えた国**の色で塗ります。国が終わったり `remove` したりすると、その前の持ち主に戻ります。
- ゾーンの ID は `map/ZONES.md` にあります。地図は現代の州・県の組み合わせなので、昔の国境は近似です。古代オリエントのように範囲がはっきりしない時代は `contested` を使うとよいでしょう。

## 君主・指導者（`rulers.json`）

```json
{ "id": "r-qing-1661", "name": "康熙帝", "aliases": ["聖祖"], "polity": "qing", "from": 1661, "to": 1722, "importance": 3, "verified": false, "uncertain": false, "memo": "" }
```

`polity` は王朝・国家の ID、`from`〜`to` は在位（在職）期間。`title` に称号（「首相」など）を書けます。

## JSON の書き方の注意

- 文字は `" "` で囲む（`true` `false` と数は囲まない）
- 最後の項目のあとに `,` を付けない
- 書き間違えると、アプリの画面に「○行目 ○文字目あたり」と場所が出ます。`npm run validate` でも点検できます

## 範囲を広げる（例：紀元前 500年〜2000年）

1. `config.json` の `range` を `[-500, 2000]` にする（紀元前はマイナス）。`anchors` に目印を足す
2. 出来事のファイルを作り（例：`events/m0500-0001.json`）、`manifest.json` の `events` の一覧に足す
3. 王朝・国家と君主を足す。別のファイルに分けてもよい：`"polities": ["polities.json", "polities-ancient.json"]`
4. `npm run validate` で点検する

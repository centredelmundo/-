# ヨコ串世界史 設計案 v0.1（確認待ち）

世界史を「同じ時代の横のつながり」で覚える学習アプリの設計メモです。
画面イメージ付きの設計案ページ: https://claude.ai/artifact/Psr68p63J5LEwfTe7XSHBT

- 対象: 早慶レベルの年代暗記
- 最初の範囲: 1500〜2000年（データを足せば古代まで広げられる作り）
- 使う場所: PC・スマホのブラウザ（ホーム画面に追加・オフライン対応）

> 追記（第2版）: 範囲を 500〜2000年に広げ、地域ごとの出来事の開閉、クイズの続きからの再開、解答後の用語の概要、

> 追記（第4版）: 勢力図を拡大したときの時代ごとの地名（都市・川・地方・海）と、前後5年の戦いの場所、

## 画面

| 画面 | 内容 |
| --- | --- |
| ヨコ年表 | 年代スライダー（−10/−1/+1/+10、キーボード←→）と「前後3/5/10/25年」。地域ごとのカードに「その年の王朝・君主」と「期間内の出来事」。ちょうどその年の出来事に朱の印。赤シート（名前を隠してタップでめくる）。用語検索で年へジャンプ。PCは地図と「王朝の帯」（1500〜2000年の王朝・政体の横並び）を同じ画面に表示 |
| 勢力図 | 選んだ年の簡易地図。地域ボタン（世界／ヨーロッパ／西アジア・インド／東アジア／南北アメリカ）。淡い色＝属国・従属地域、斜線＝範囲が不確か・係争中 |
| クイズ | ヨコ記述（◯年ごろ、A・B・Cで何が起きていた？）、君主・王朝ヨコ、年代当て、出来事当て、並べ替え、同時代えらび。答えたあとに「同じころの世界」を表示。設定で範囲・地域・重要度・問題数。利用者が読み込んだ一問一答（【　】を答える）も出せる |
| 復習 | まちがえた問題を自動登録し、間隔をあけて再出題（当日→1日→3日→7日→14日→30日）。地域×世紀の苦手マップ。学習記録の書き出し・読み込み |
| データ確認（設定内） | 全データを年代順に一覧。年号は要確認の印で絞り込んで修正、概要・画像は確かめたら「確認した」。PCでJSONに書き出してリポジトリに反映 |

## データ（`data/` のJSON）

```
data/
├─ config.json      年の範囲・地域の並び・初期設定
├─ regions.json     地域の定義
├─ events/          出来事（年代ごとにファイル分割）
├─ polities.json    王朝・国家（期間・色・領域の変化）
├─ rulers.json      君主・指導者（在位）
└─ map/             ゾーン（自動生成）とゾーンの日本語名
```

出来事の例:

```json
{
  "id": "1648-westphalia",
  "year": 1648,
  "title": "ウェストファリア条約",
  "answers": ["ヴェストファーレン条約"],
  "regions": ["ce", "we"],
  "importance": 3,
  "desc": "三十年戦争の講和。スイス・オランダの独立を承認",
  "uncertain": false,
  "memo": ""
}
```

### 確認の印

| 項目 | 意味 | 最初の値 | 表示 |
| --- | --- | --- | --- |
| `uncertain` | 年代に自信がない／説・数え方が分かれる | AIが判断して `true` | 要確認 |
| `memo` | 迷った理由・別の説・世界史の窓の年など | 空 | 印の説明 |
| `importance` | 重要度 ★1〜3 | AIが付ける | クイズの絞り込み |

1年でも迷う年代、即位年・開始年など数え方が分かれるもの、教科書で年がちがうものは `uncertain: true` にして理由を `memo` に書く。年代は世界史の窓と照合した（第3版）。以前の「用語集で確認」の印（`verified`）は、この照合を終えたので廃止した。

### 範囲の拡大

`config.json` の `"range"` を広げ、`events/` にファイルを足す。紀元前は負の数（前221年 → `-221`。0年はなし）。

### 勢力図（ゾーン方式）

Natural Earth（パブリックドメイン）の州・県境界を組み合わせて約200のゾーンを作り、王朝ごとに「何年にどのゾーンを得た（add）・失った（remove）か」を `territory` に書く。同じゾーンを複数の国が持つ場合は、後から得た国を優先。

## 記述式の採点

1. 表記をそろえる（全角/半角、ひらがな/カタカナ、ェ/エ、ヴ/ブ、＝・の有無、一世/1世）
2. 正解の語・別名・キーワードの組み合わせ（例: 「明」＋「滅亡」）と照合。文で答えてもよい
3. 時期・地域を調べ、「時期ちがい」「地域ちがい」は実際の年を表示
4. ×でも「正解にする」で自己判定（データ追加の候補として記録）

厳しさは「ふつう」「きびしめ（1文字ちがいは×）」から選ぶ。

## しくみ

- 静的Webアプリ（HTML・CSS・JavaScript）。サーバー・ビルド不要。PWAでオフライン対応
- 学習記録は localStorage。端末間は書き出し・読み込みで移す
- JSONの書式エラーはファイル名と行番号を表示。点検スクリプト（必須項目・年の範囲・ID重複・地域名/ゾーン名）と採点ロジックのテストを用意

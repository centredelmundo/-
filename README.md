# ヨコ串世界史

世界史を「同じ時代のヨコのつながり」で覚えるための学習アプリです。PC とスマホのブラウザで使えます。
早慶レベルの年代を、同時代の勢力図を見ながら暗記することをめざしています。

- 公開後の URL（GitHub Pages を有効にしたあと）：**https://centredelmundo.github.io/-/**
- いまの収録範囲：**前800年（ギリシアでポリスが生まれたころ）〜2000年**

## できること

| 画面 | 内容 |
| --- | --- |
| ヨコ年表 | 年代スライダーを動かすと、その年の前後（±3・5・10・25・50年）の王朝・君主・出来事が地域ごとに横に並ぶ。地域は中国・朝鮮・内陸アジア・東南アジア・南アジア・西アジア・アフリカ・ヨーロッパ（東・中央・西）・南北アメリカ。日本は参考、20世紀は「国際」の欄もある。**地域名をタップすると、その地域の歴史を出来事ごとに縦に並べた画面**が開く（次の行）。**「出来事 ◯件」をタップすると、その地域の出来事を開閉**できる（「すべて開く」「すべて閉じる」つき。開閉の状態は覚えておく）。赤シート（名前を隠す）と検索つき（**検索で作品・建築など写真のあるものを選ぶと、写真つきの詳細がすぐ開く**。候補には「写真」と出る）。**年を変える −10・−1・+1・+10 は長押しすると、一定の速さで続けて変わる** |
| 地域の歴史（ヨコ年表の地域名から） | その地域の出来事を古い順に縦に並べた画面。世紀ごとの見出しに、その世紀のおもな王朝・国家が出る。重要度（★3だけ・★2以上・すべて）・文化史・一問一答でしぼれる。ヨコ年表で見ていた年の位置に「いまの年」の印が付き、開くとそこまで移動する。出来事をタップすると概要、上の地域名で別の地域に切りかえ、「← ヨコ年表」で戻る |
| 勢力図 | その年の勢力の範囲を色分けした簡易地図。国をタップすると、その年の王朝・君主・出来事が出る。境界は現代の州・県を組み合わせた近似で、範囲が不確かな所・係争中の所は斜線。<br>**地図を拡大すると、その時代の都市・川・地方・海の名前が、国名と重ならない所に小さく出る**（例：ビザンティウム → コンスタンティノープル（330年〜）→ イスタンブル（1453年〜）。拡大するほど細かい地名まで出る。右下の「地名」で消せる）。<br>**有名な戦いの場所は、選んだ年の前後5年に起きたものだけ ✕ 印と名前で出る**（拡大したとき。タップすると詳細）。ヨコ年表の画面の地図も同じ |
| クイズ | ヨコ記述（「1200年ごろ、中国・西アジア・ヨーロッパでは何が起きていた？」）・君主のヨコ・年代当て・出来事当て・並べ替え・同時代えらびの6形式と、自分で読み込んだデータで出す**一問一答**（下を参照）。記述は自動で採点し（表記ゆれ・送り仮名・1〜2字の誤字は許す）、「正解にする」で自分の判定に変えられる。<br>**途中で別のタブに移ったりアプリを閉じたりしても、次に開くと続きから再開**（書きかけの答えも残る）。<br>**解答後は、問題文や選択肢の用語（点線の下線）をタップすると1〜2文の概要**が出る。<br>**「文化史だけで出題する」では、作品・建築の写真つき**で出題（写真は採点前は作品名を伏せて出し、採点後に作品名と出典・ライセンスを出す） |
| 復習 | まちがえた問題を、10分後 → 1日後 → 3日後 → 7日後 → 14日後 → 30日後と間をあけて出し直す。苦手リスト、地域×世紀の弱点マップ、連続学習日数 |
| データ確認（右上の ☑） | 「年号」では要確認の印がついた項目を見て、年やメモを直せる。「概要」「画像」は1件ずつ確かめて「確認した」を押せる |

## データについて（大切）

- 年代・用語・概要のデータは **AI が作ったもの**です。
- 年代は **世界史の窓（https://www.y-history.net）と照らし合わせました**（2026年11月）。用語の索引で世界史の窓のページが見つかった約1,760件について、
  ページに書かれた年・在位と、データの年・概要の中の年を突き合わせ、さらに世界史の窓の「用語年表」とも比べました。
  ちがっていたものは直し、説が分かれるもの（世界史の窓と教科書で年がちがうものなど）は「要確認」の印を付けて、メモに世界史の窓の年を書いています。
  世界史の窓にページが見つからなかった約1,000件（細かい出来事・人物など）は、1件ずつの照合はしていません。
- 以前あった「用語集で確認」の印（`verified`）は、この照合を終えたのでなくしました。「要確認」の印（403件）はそのまま残しています（理由はメモにあります）。
- 収録数：出来事 1556件（うち文化史 239件。紀元前 135件、1〜499年 105件、500〜1499年 316件）・王朝/国家 592件・君主/指導者 639人。
  地図の地名は都市 310・地方 93・海 31・川 67、戦いの場所は 90件。

### 概要（用語をタップすると出る1〜2文）

- すべての出来事・王朝・人物（2787件）に概要があります。概要は AI が自分の言葉で書いたもので、世界史の窓の文章は使っていません。
- 概要の中の年は、上の照合で世界史の窓と突き合わせました。内容（だれが・何をしたか）は抜き取りで世界史の窓のページと読み比べ、食いちがいは見つかりませんでしたが、全件を読み比べたわけではありません。
  そのため概要には今も「確認済み」の印（`descVerified`）があり、最初は「概要は未確認」です。気になるものは「世界史の窓で調べる」から確かめ、データ確認の「概要」で「確認した」を押してください。
- 出来事の概要は「出来事当て」の手がかりにも使います。答えになる言葉が入っていても、出題中は「＿＿」で伏せ、採点後に元の文を出します。

### 作品・建築の写真

- 文化史の出来事（239件のうち215件）と、運河・都城などの建設7件（計222件）に、写真の元になる記事またはファイルを指定しています（例：`"image": "ja:落穂拾い (ミレー)"`）。
  文化史クイズのほか、**ヨコ年表の検索で選んだとき**と、用語をタップして出る詳細に写真が出ます。
  写真そのものは **表示するときに Wikimedia Commons / Wikipedia から取得** し、利用条件がはっきりした自由なライセンス（パブリックドメイン・CC BY・CC BY-SA など）のものだけを表示します。
  写真の下に作者・ライセンス・Commons のファイルページへのリンクを出します。
- 著作権が切れていない作品（ピカソ「アヴィニョンの娘たち」、シュルレアリスム宣言）は写真を指定していません。
- 記事の代表画像を使うので、作品そのものではなく作者の肖像などが出ることがあります。どの写真も最初は「画像は未確認」なので、データ確認の「画像」で確かめてください（ちがうときは「修正」で記事名やファイル名を変えられます）。
- Wikipedia の記事は名前が変わることがあるので、指定した記事が見つからないときは、記事名で検索していちばん近い記事の写真を使います。
- 写真の表示にはインターネット接続が必要です（一度表示した写真は端末に保存され、オフラインでも出ます）。
  学校の端末などでフィルターがあるときは、`upload.wikimedia.org`・`commons.wikimedia.org`・`ja.wikipedia.org`・`en.wikipedia.org` が開けないと写真は出ません（アプリのほかの機能は使えます）。

### 地図の地名・戦いの場所

- 地名は `data/map/places.json`（都市・地方・海）と `data/map/rivers.json`（川）にあります。
  都市の名前は、時代によって変わるもの（ビザンティウム／コンスタンティノープル／イスタンブル、燕京／大都／北平／北京、ペテルブルク／ペトログラード／レニングラード、ツァーリツィン／スターリングラード／ヴォルゴグラードなど）を、変わった年ごとに書き分けています。
  滅びた都市（バビロン・ニネヴェなど）は、その年からは出しません。
- 戦いの場所は、出来事の `place`（経度・緯度）で指定しています（90件）。前800年より前の戦い（ラガシュとウンマの争い、カデシュの戦いなど）は収録範囲の外なので入っていません。

## 一問一答（自分で読み込むデータ）

- 一問一答の文（【　】の中が答え）を JSON ファイルで読み込むと、クイズの形式「一問一答」で、【　】の部分を答える問題が出せます。
  答えは記述式で、表記ゆれ（イェルサレム／エルサレム、「（　）」の中の別名、「1905年」と「1905」など）を許して採点します。章でしぼることもできます。
- 文の中に年（◯年）や世紀がある問題は、ヨコ年表にも「一問一答」の印つきの出来事として並びます（タップすると文全体と出典が出て、その問題を解けます）。
  アプリにすでにある出来事と同じ問題は、別の行を作らず、その出来事の行に印を付けます。設定で年表に出さないようにもできます。
- **読み込むファイルは公開しているアプリやこのリポジトリには入れていません**（市販の問題集の音声を文字起こししたものなど、著作権のある文章を公開しないため）。
  ファイルは設定画面の「一問一答（自分で読み込むデータ）」から読み込みます。この端末のブラウザにだけ保存されるので、PC とスマホではそれぞれ読み込んでください。
- ファイルの形は [data/README.md](data/README.md) の「一問一答のファイル」にあります。

## 公開のしかた（GitHub Pages）

1. GitHub でこのリポジトリを開き、**Settings → General** のいちばん下 **Danger Zone → Change visibility → Public** にする
   （無料プランで GitHub Pages を使うには、公開リポジトリにする必要があります）
2. **Settings → Pages → Build and deployment** で
   Source を **Deploy from a branch**、Branch を **`claude/world-history-timeline-app-ykwk8f`**（main にまとめたあとなら `main`）と **/ (root)** にして Save
3. 数分たつと https://centredelmundo.github.io/-/ で開けます
4. スマホでは、ブラウザで開いて「ホーム画面に追加」すると、アプリのように使えます。一度開けば電波がなくても使えます

## 学習記録

- 記録はブラウザの中（localStorage）に保存されます。サーバーには送りません。解答中のクイズも同じ場所に保存されるので、続きから再開できます。
- **PC とスマホの記録は別々**です。「復習」画面の「学習記録の書き出し・読み込み」で、片方で書き出し → もう片方で読み込むと合わせられます。
- ブラウザのデータを消すと記録も消えるので、ときどき書き出して控えを取ってください。

## 自分の PC で動かす

ファイルをダブルクリックで開くと動きません（ブラウザの決まりで、データの読み込みができないため）。次のどちらかで開いてください。

```sh
python3 -m http.server 8000     # → http://localhost:8000/ を開く
npm run serve                   # 同じ
```

データを直したら、点検とテストを走らせると安心です（Node.js 22 以上）。

```sh
npm run validate   # データの点検（JSON の書き間違い・参照の切れ・年の前後・概要や画像の指定など）
npm test           # 採点・復習間隔・クイズ作成・画像の取得などのテスト
```

## フォルダの中身

```
index.html              画面のもと
css/app.css             見た目（ライト／ダーク）
js/main.js              画面の切りかえ
js/core/                データの読み込み・採点・復習間隔・クイズ作成・写真の取得（画面に依存しない）
js/views/               各画面（年表・勢力図・地図の地名と戦い・地域の歴史・クイズ・復習・データ確認・設定・用語の概要）
data/                   年代データ（JSON）… 編集のしかたは data/README.md
data/map/zones.json     勢力図の地形（tools/build-map.mjs で作る）
data/map/places.json    勢力図の地名（都市・地方・海。時代ごとの名前）
data/map/rivers.json    勢力図の川（tools/build-rivers.mjs で作る）
tools/validate.mjs      データの点検
tools/build-map.mjs     地図データの作成（ふつうは使わない）
tools/build-rivers.mjs  川のデータの作成（ふつうは使わない）
tests/                  テスト
docs/design.md          設計
sw.js, manifest.webmanifest, icons/   ホーム画面への追加・オフライン用
```
